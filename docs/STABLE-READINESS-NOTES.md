# Stable-readiness P0–P3 scope

This pass is intentionally limited to QNAP stable-readiness hardening: fail-closed routing, first-admin bootstrap protection, listener and source-fetch exposure reduction, QNAP image/runtime surface reduction, Web/Control privilege separation, authenticated readiness, optional HTTPS cookie hardening, and release supply-chain metadata. It does not redesign the existing same-LAN TUN data plane or the persisted runtime ownership model.
